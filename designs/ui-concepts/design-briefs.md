# UI concept directions

Generated using the built-in image generation tool for design selection. Main application and in-game overlay shown together in each image. These are visual proposals, not implemented UI; generated labels, rarity legends and sample values are illustrative and must be replaced with current application behavior during implementation.

Shared prompt: high-fidelity, flat Windows screenshot-style board with a main desktop application view and in-game overlay view. Same seven modules, enable checkboxes, settings cogs, workshop/history/stash navigation; compact route legend, ground path, monster/encounter icons, item prices, inventory worth and rare assessment. No marketing dashboard, bento cards, slogans or excessive glow.

A / Quiet Desktop: compact native utility, charcoal and gray, cool blue selection accent, top tabs, text-only module list, settings inspector and small dark overlay panels.

B / Wraeclast Field Kit: restrained gothic game interface, blackened iron and subtle leather, antique brass, ivory text, vertical navigation, integrated ledger and small framed overlay placards.

C / Modern Field Notes: light off-white editorial main application, ink text, oxblood accent, ruled rows and right-hand settings sidebar; compact dark overlays with ivory text and an oxblood rule.
