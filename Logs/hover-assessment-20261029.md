# Hovered rare assessment

Items & stash now has an Assessment tab with an enable switch, Always on / Hotkey only modes, a configurable shortcut (Alt+F by default), and the existing build preference. The compact panel is placed beside the native item tooltip. The shortcut opens a larger pinned breakdown in either mode. Closing returns to normal hover behavior; the same item can reopen. Interactive panels reject mouse activation to preserve PoE focus. The shortcut is registered only while the module/feature is enabled, preview is off, and PoE is foreground. A 350 ms same-instance hover cache and up to two 60 ms retries tolerate tooltip changes at shortcut time. No game inputs or clipboard copies are generated.

The independent reader uses external profile values: in-game state hover +0x618; hovered inventory element item +0x420; tooltip holder +0x1f8 followed by one pointer indirection; plain/styled native text +0x4f8/+0x338. Text traversal is bounded to 256 item-owned nodes and 16 levels with pointer revalidation. Non-item hovers are excluded. Non-text containers do not prevent walking their children. Styled text is a fallback when the plain cache is empty. Multiline decoding is allowed only for tooltip calls; ordinary game identifiers retain their previous control-character checks. These values were resolved against the reference assembly in development; it is not a runtime dependency.

Live captured data identified Brood Ward, General's Brigandine, with six linked sockets. A replay through the production UTF-16/vector/tooltip readers decoded its six explicit modifier lines, affix tiers, roll positions and crafted resistance. This caught an integration bug absent from early mocked tests: ordinary string validation had rejected all multiline name/affix blocks. The final regression exercises the actual byte/string decoder, preserves strict validation elsewhere, and covers empty plain caches, non-text parents and hover replacement.

Panels hide while PoE is unfocused or data is stale. A pinned breakdown remains through mouse movement, but clears on loading, instance changes, disabling, preview or panic. Neither unrecognized nor unsupported modifiers are interpreted as worthless. The manual workshop remains available.

## Assessment logic

Life, ES, speed and added-damage references account for equipment slot; common regular/abyss jewels have their own references. Tier-one annotations support strong-roll recognition; within-tier roll positions are shown separately and do not promote low-tier affixes to top-tier status. Hybrid affix display lines receive diminishing additional contribution. Complementary physical/speed, minion damage/speed, life/resistance, suppression/defence, ES, mana, DoT/gem-level and attribute combinations receive explicit bonuses. Additional arrows, extra damage, curses, cooldown recovery and other common utility affixes have rules. Filler such as light radius and stun recovery is recognized without increasing the score. Unknown modifiers remain visible for review. Cluster jewels, maps, flasks and unidentified items remain unrated.

Socket count and largest linked group are distinct. A six-link gets an explicit callout and an overall utility floor of 6.5, while the separately reported affix score remains unchanged; the test chest has 5.2 affix quality and 6.5 overall utility. Five links and six unlinked sockets have separate contextual notes. Weapon physical/elemental DPS is calculated from displayed damage and attack-speed properties where present. None of these heuristics claims a sale price or recommends automatic discarding.
